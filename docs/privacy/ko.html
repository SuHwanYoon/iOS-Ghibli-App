개인정보 처리방침 (Privacy Policy)

최종 수정일: 2026년 10월 21일
핵심 요약: '도토리 서재'는 사용자의 어떠한 개인정보나 기기 식별 정보를 서버로 수집·전송·공유하지 않습니다.

1. 수집하는 개인정보 항목

'도토리 서재' 애플리케이션은 회원가입이나 로그인이 필요하지 않으며, 사용자의 이름, 이메일, 전화번호, 위치 정보, 기기 고유 식별자(IDFA 등)를 포함한 어떠한 개인정보도 수집하거나 저장하지 않습니다.

2. 기기 내 로컬 데이터 저장 (UserDefaults)

앱은 원활한 사용자 경험 제공을 위해 오직 기기 내부 저장소(UserDefaults)에 한하여 다음의 환경설정 정보만을 보관합니다:

  • 사용자가 선택한 화면 테마 모드 (시스템 설정 / 라이트 / 다크)
  • 사용자가 선택한 앱 언어 설정 (시스템 기본 / 한국어 / English / 日本語)
  • 사용자가 즐겨찾기(Favorite)로 등록한 영화 ID 목록

위 데이터는 사용자의 기기 내부에만 암호화되어 안전하게 보관되며, 외부 서버로 절대 전송되지 않습니다. 앱을 삭제할 경우 해당 로컬 데이터는 기기에서 영구히 삭제됩니다.

3. 외부 API 서비스 이용

본 앱은 스튜디오 지브리 영화 및 등장인물에 관한 공개 정보를 표시하기 위해 공개 오픈 API(Ghibli REST API)를 호출합니다. 이 통신 과정에서 사용자를 식별할 수 있는 어떠한 개인 식별자도 서버로 전달되지 않습니다.

4. 지식재산권 면책 조항

'도토리 서재'는 개인이 제작한 비공식 팬 메이드(Fan-made) 가이드 앱입니다. 본 앱은 Studio Ghibli와 어떠한 공식적인 제휴나 후원 관계도 없으며, 앱 내에 표시되는 모든 작품 및 캐릭터 이미지, 텍스트 정보의 저작권은 해당 저작권자에게 있습니다.
